# Selective-Quotient Modulation (SQM)

## Calibration-light communication for short wireless packets

Research and reproducibility materials for **“Selective-Quotient Modulation for Calibration-Light Short-Packet Wireless Links”**, by **Dhruv Kumar and Michael Georgiades**.


## What is the idea?

A short packet may spend a substantial fraction of its samples on learning a channel or calibrating the receiver. SQM instead asks: **which unknown transformations can be tolerated without estimating them individually, and how much tolerance becomes too much?**

- **Remove static affine I/Q nuisance analytically:** temporal centering removes a constant DC offset; the row space of a noiseless rank-two I/Q block is unchanged by any common invertible real 2 × 2 left transformation.
- **Retain only selected temporal nuisance directions:** message-dependent low-rank explanation spaces model carrier-frequency offset (CFO) and frequency-selective fading.
- **Train against the relevant ambiguity:** incidence-aware codebook design discourages a received plane generated by one message from fitting another message’s explanation space.
- **Choose the nuisance rank deliberately:** too small a rank loses useful signal components; too large a rank makes wrong messages easier to explain.

The exact invariance is a **noiseless algebraic identity**, not a claim that noise, information loss, or all hardware impairments disappear. CFO is searched over, not eliminated for free.

## What the reported results do—and do not—show

The main fractional-delay 3GPP TDL-A comparison uses **8 information bits, 256 messages, 16 complex samples, mean block energy 16**, I/Q condition number **1.5**, and **three independent final seeds**. Physical CFO is uniform over **±4 degrees/sample**; the decoder searches **−5 to +5 degrees/sample in one-degree steps**.

At **10 dB**, the stored main rerun reports:

| Receiver | Packet error rate (PER), mean ± two-sided 95% t-interval half-width |
|---|---:|
| SQM, rank 4 | 0.0658 ± 0.0435 |
| Practical pilot-aided TDL-aware CP-OFDM | 0.2264 ± 0.0509 |
| Full-oracle CP-OFDM | 0.0181 ± 0.0104 |

Source: [`Data/final_rerun_fractional_tdla_headtohead.csv`](Data/final_rerun_fractional_tdla_headtohead.csv). Intervals use three seed-level PERs, **df = 2**; 1,200 blocks/SNR/seed, 3,600 blocks per point.

A **separate shared-seed coded-control experiment** reports:

| Receiver | PER at 10 dB, mean ± 95% t-interval half-width |
|---|---:|
| SQM, rank 4 | 0.0650 ± 0.0090 |
| Pilot-free coded OFDM, TDL-A-marginal ML | 0.0831 ± 0.0150 |
| Rate-matched pilot-aided coded OFDM | 0.2442 ± 0.0075 |
| Practical OFDM with unknown I/Q/DC | 0.3061 ± 0.0209 |

Sources: [`reviewer_baselines_summary.csv`](Data/reviewer_baselines_summary.csv) and [`reviewer_baselines_paired.csv`](Data/reviewer_baselines_paired.csv). The paired difference **SQM minus pilot-free coded OFDM is −0.0181 ± 0.0240**, so these three seeds **do not establish a statistically separated advantage over that strong pilot-free baseline**. Do not combine the SQM mean from one experiment with the paired difference from the other.

**Interpretation:** evidence supports a calibration-light, regime-specific approach, not universal superiority over coded OFDM. Full-oracle OFDM remains better. BMOCZ is stronger at low SNR in its native two-tap setting; Grass-Lattice is tested in a native flat-fading setting, not a common TDL-A leaderboard. Decoder-only online rank controllers do not consistently improve PER. The 10-bit scaling result uses a random stress-test codebook, not an optimized 10-bit design. No RF energy, hardware latency, arbitrary phase-noise robustness, or real-world SDR gain is established.

## Installation

Use Python **3.10 or later** and a virtual environment; package preparation was tested on Python **3.13**. The author-supplied historical environment is in [`environment.txt`](environment.txt); it is a record, not a portable lockfile.

For plotting, CSV audits, and the main NumPy evaluation:

```bash
git clone https://github.com/Dhruvkumar25/Selective-Quotient-Modulation.git
cd Selective-Quotient-Modulation
python -m venv .venv
source .venv/bin/activate             # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements-review.txt
```

For all original scripts, additionally install the complete [`requirements.txt`](requirements.txt), including SciPy and PyTorch. PyTorch is needed for reference codebook training; SciPy is imported by the Grass-Lattice evaluator. Neither is needed to regenerate the manuscript figures from stored CSVs. Installation and full stochastic retraining were **not** revalidated for every possible platform.

## Statistics, known limitations, and reporting problems

- Main and coded-control intervals are computed across seed-level PERs with a two-sided t multiplier for **exactly three seeds**, not across individual packets. Some evaluator code hard-codes df = 2; do not change the seed count and assume the uncertainty remains valid.
- Earlier/smoke/diagnostic CSVs may use different budgets or normal-approximation half-widths. They are retained for provenance, not interchangeable with the current manuscript tables.
- The online sensitivity and transient figures have specific inference caveats in `docs/AUTHOR_REVIEW.md`. Do not treat them as uniformly df = 2 main-result intervals.
- `Code/config.json` is required by scripts importing `experiment_config.py`. Some other scripts still contain constants of their own. Editing that JSON alone does not guarantee that every experiment changes consistently.
- Finite-block fractional-delay filtering and OFDM frequency-response synthesis use different implementation paths; see the author-review items before interpreting “matched channel” as sample-for-sample equivalence.

For questions, open a GitHub Issue and include the **commit SHA**, command, Python/dependency versions, full traceback, and whether you used released data or a fresh run. Do not include credentials or private information.
